# Simulation Data

Allpix² ROOT output files (`*.root`) live here but are **not committed to git**
(~hundreds of MB per full sweep). They are regenerated by the run scripts in
`simulation/`, e.g.:

```bash
docker compose run allpix bash        # enter the Allpix² container
./simulation/run_full_chip_comparison.sh
```

File naming follows `<scenario>_<chip>_<energy>_<material>.root`, e.g.
`cat1_medipix3_60keV_steel.root`.

If you need an existing dataset without re-running the simulations, ask a team
member for a copy of this directory.
